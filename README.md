# CAFEDOYS ☕🍰

감성적인 디저트 카페를 콘셉트로 제작한 React 웹사이트입니다.
사진과 타이포그래피를 중심으로 심플하고 편안한 카페 분위기를 표현했습니다.

## Demo

https://raccooney.github.io/dessert-cafe-portfolio/

## Features

* 반응형 웹 디자인
* Hero 이미지와 브랜드 소개
* Signature 메뉴 소개
* Coffee / Dessert 메뉴판
* Location 섹션
* 전화 및 Instagram 연결
* 모바일 화면 최적화

## Tech Stack

* React
* JavaScript
* CSS
* Vite
* GitHub Pages

## Project Purpose

React와 CSS를 활용하여 실제 소규모 카페에서 사용할 수 있는 형태의 브랜드 웹사이트를 제작하는 것을 목표로 했습니다.

카드 중심의 일반적인 레이아웃 대신 큰 이미지, 여백, 타이포그래피를 활용해 감성적인 디자인을 구현했습니다.
